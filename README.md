# Ubiaja Groundwater Assessment (VES)
Undergraduate thesis project analyzing groundwater potential in the Ubiaja area, Edo State, Nigeria.

## Project Overview
*   **Method:** Vertical Electrical Sounding (VES) using Schlumberger array.
*   **Software:** ZONDIP1D, Surfer.
*   **Key Findings:** Derived Dar-Zarrouk parameters (Transmissivity & Longitudinal Conductance) to identify high-yield aquifer zones. The southeastern area (VES 11 & 13) showed the highest potential.
